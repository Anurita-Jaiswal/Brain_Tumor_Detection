# 🧠 Brain Tumor Detection System

A Deep Learning based Brain Tumor Detection Web Application built using TensorFlow and Streamlit.

## 📌 Features

- Upload MRI Brain Images
- Detect Brain Tumor Type
- Predict 4 Classes
  - Glioma Tumor
  - Meningioma Tumor
  - Pituitary Tumor
  - No Tumor
- Shows Prediction Confidence
- User Friendly Interface

---

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow
- OpenCV
- Matplotlib

---

## 📂 Dataset

Brain MRI Images Dataset containing:

- Training Images
- Testing Images

Classes:

- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Brain_Tumor_Detection.git
```

Go to project folder

```bash
cd Brain_Tumor_Detection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
